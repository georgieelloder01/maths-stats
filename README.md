# Maths and Stats Coursework

MSc Bioinformatics coursework (Mathematical & Statistical Analysis using R) exploring
probability simulation, data quality control, and regression modelling.

**Contents:**
- Simulating a board-game Markov process (custom functions, corrected logic)
- BMI data cleaning, quality control, and outlier detection using PCA
- Simple and multiple linear regression modelling of body fat, with residual diagnostics

**Files:**
- `Maths_and_Stats_Coursework.Rmd` — full analysis and write-up
- `Functions_for_CW.R` — helper functions sourced by the main analysis

**Tools:** R, dplyr, ggplot2, PCA, linear regression

> Note: the underlying dataset (`assess_data_1225.Rdata`) is not included here, as it
> contains participant-level health data (BMI, body fat, age, etc.) supplied for
> coursework purposes only.
